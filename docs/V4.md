# v4: fresh bot (branch `v4-fresh`, folder `v4/`)

Written from scratch on Oct 4. v3.5 (`macpoker-scaffold/`) was used only as a reference opponent.

## How it plays

- **Preflop** (`foldv4.Brain.preflop`): percentile ranges from `pf_table.py` (169 hand classes ranked by
  equity vs 1 and 3 random hands). Opens tighten with more players behind. Calls and 3-bets scale with the
  raiser's observed opening rate and the raise size. Big raises and jams are called by where our hand sits
  in that raiser's range.
- **Postflop** (`foldv4.Brain.postflop`): an expected-value engine.
  1. Each opponent's range (1,326 combos) is rebuilt from this hand's actions. Every action multiplies a combo's
     weight by how often the **real ladder field** takes that action with that hand class, in that spot and at
     that bet size (`field_model.py`, fitted from scraped games). Weights are tempered by the opponent's own
     looseness and aggression in this game.
  2. One Monte Carlo sample set gives our equity against those ranges, and is reweighted for every scenario.
  3. Check, call, fold and each bet size are scored in chips. The field's fold/call/raise rates per hand class
     predict how each opponent answers each size, scaled by that opponent's own fold rate.
  4. Guards: no shove above 1.6x pot; a bluff must beat checking by 10% of the pot; calls of pot-size or bigger
     bets need a 4%-of-pot margin.
- About 15-70 ms per decision and about 4 s per 100-hand game. Every hook is wrapped, so the fallback is
  check/fold.

## Rebuilding the data

```bash
python tools/scrape_ladder.py          # fresh games into games/
python tools/v4/fit.py                 # -> v4/field_model.py + opponents/clone_data.json
python tools/v4/make_preflop.py        # -> v4/pf_table.py (only if the evaluator changes)
```

## Testing

- `tools/v4/arena.py A/main.py B/main.py --tables 60`: 5-seat tournament tables. The other 4 seats are
  **behavioural clones of real ladder bots** (`opponents/clone.py`: each bot's own action frequencies per spot,
  fitted from its ladder games). Each table is a full duplicate set, and placement points are scored like the
  tournament. `--pool file:tag,house:call,...` uses hand-written bots instead.
- `tools/v4/river_check.py A/main.py B/main.py` (and `STREET=turn` / `STREET=flop`): puts the build in every
  real heads-up spot where a bot faced a bet, with the exact message stream that bot saw, and scores call/fold
  against the bettor's **real cards**.
